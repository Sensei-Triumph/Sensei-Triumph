### 🚀 About Me

A seasoned AWS DevOps and cloud engineer. I build and deploy hands-on projects covering CI/CD pipelines, containerised applications, infrastructure as code and serverless architectures. My work on AWS with Terraform, such as a static portfolio served through CloudFront from a private S3 bucket with a least-privilege IAM deployment user, reflects how I approach infrastructure: secure, repeatable and automated. I’m currently focused on strengthening my pipeline and cloud skills, one deployed project at a time.

🌱 &nbsp;I'm currently learning **Go and Kubernetes**
